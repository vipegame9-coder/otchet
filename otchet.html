ПРАКТИЧЕСКАЯ РАБОТА №1

Проверка загруженности фона реки

Цель работы: определить, загрязнена ли река выше места сброса сточных вод, и учитывать ли её ассимилирующую способность при расчёте ПДС.

Исходные данные (Вариант 8):

ВеществоC₀, мг/лПДК, мг/лЛПВ
БПК₅1,43общесанитарный
Взвешенные вещества1212,75общесанитарный
ХПК0,0315общесанитарный
Нефтепродукты0,020,05рыбохозяйственный
Сульфаты160100санитарно-токсикологический
Хлориды90300санитарно-токсикологический
Нитраты840санитарно-токсикологический

Методика расчёта:

Загруженность фона реки проверяется по условию (2.3) для каждой группы ЛПВ:

∑ (C₀ / ПДК) < 1     (2.3)

Если условие выполняется — река чистая, ассимилирующая способность учитывается. Если нет — река загрязнена, контрольный створ назначается в месте сброса.

Расчёт:

1. Общесанитарная группа ЛПВ:

(C_БПК5 / ПДК_БПК5) + (C_взв / ПДК_взв) + (C_ХПК / ПДК_ХПК) = (1,4 / 3) + (12 / 12,75) + (0,03 / 15) = 0,467 + 0,941 + 0,002 = 1,410

1,410 > 1 → условие не выполняется, река загрязнена по общесанитарному показателю.

2. Рыбохозяйственная группа ЛПВ:

(C_нефт / ПДК_нефт) = (0,02 / 0,05) = 0,4

0,4 < 1 → условие выполняется, по нефтепродуктам фон не перегружен.

3. Санитарно-токсикологическая группа ЛПВ:

(C_сульф / ПДК_сульф) + (C_хлор / ПДК_хлор) + (C_нитр / ПДК_нитр) = (160 / 100) + (90 / 300) + (8 / 40) = 1,6 + 0,3 + 0,2 = 2,1

2,1 > 1 → условие не выполняется, река загрязнена по санитарно-токсикологическому показателю.

Вывод:

Так как хотя бы в одной группе ЛПВ (фактически в двух) сумма отношений C₀/ПДК > 1, река считается загрязнённой. Ассимилирующая способность водного объекта не учитывается. Контрольный створ назначается в месте сброса сточных вод.

ПРАКТИЧЕСКАЯ РАБОТА №2

Расчёт кратности разбавления при сбросе в водоём

Цель работы: рассчитать кратность разбавления сточных вод в водоёме методом М.А. Рудельса.

Исходные данные (Вариант 8):

ПараметрОбозначениеЗначение
Расчётный расход СВq_св0,073 м³/с
Средняя глубина водоёмаH4 м
Скорость ветра над водойV_в6 м/с
Расстояние до контрольного створаL325 м
Тип выпуска—в верхнюю треть глубины

Методика расчёта:

Общая кратность разбавления:

n = n_нр * n_ор     (2.5)

1. Кратность начального разбавления (выпуск в верхнюю треть глубины, формула 2.6):

n_нр = (q_св + 0,00215 * V_в * H²) / (q_св + 0,000215 * V_в * H²)

Расчёт:

H² = 4² = 16 м²
V_в * H² = 6 * 16 = 96
n_нр = (0,073 + 0,00215 * 96) / (0,073 + 0,000215 * 96) = (0,073 + 0,2064) / (0,073 + 0,02064) = 0,2794 / 0,09364 ≈ 2,98

2. Кратность основного разбавления (формула 2.8):

n_ор = 1,85 + 2,32 * √( L / (4,41 * H1,7) ) / √( 0,41 + 0,0064 * L )

Расчёт:

H1,7 = 41,7 ≈ 10,556
4,41 * H1,7 = 4,41 * 10,556 ≈ 46,55
L / (4,41 * H1,7) = 325 / 46,55 ≈ 6,982
√6,982 ≈ 2,642
0,41 + 0,0064 * 325 = 0,41 + 2,08 = 2,49
√2,49 ≈ 1,578
n_ор = 1,85 + 2,32 * (2,642 / 1,578) = 1,85 + 2,32 * 1,674 ≈ 1,85 + 3,88 = 5,73

3. Общая кратность разбавления:

n = n_нр * n_ор = 2,98 * 5,73 ≈ 17,1

Ответ:

  • Кратность начального разбавления: n_нр ≈ 2,98
  • Кратность основного разбавления: n_ор ≈ 5,73
  • Общая кратность разбавления: n ≈ 17,1

ПРАКТИЧЕСКАЯ РАБОТА №3

Расчёт кратности разбавления при сбросе в водоток (отдельный выпуск)

Цель работы: рассчитать кратность разбавления сточных вод в водотоке методом Фролова-Родзиллера.

Исходные данные (Вариант 8, Приложение В):

ПараметрОбозначениеЗначение
Среднегодовой минимальный расход воды в рекеQ0,8 м³/с
Расчётный расход СВq_св0,01 м³/с
Средняя глубина водоёмаH_ср1,5 м
Средняя скорость теченияV_ср0,42 м/с
Коэффициент извилистостиφ1,8
Расстояние до контрольного створаL500 м

Методика расчёта:

Метод Фролова-Родзиллера применяется при условии:

0,0025 < q_св / Q < 0,1     (2.10)

1. Проверка условия применимости метода:

q_св / Q = 0,01 / 0,8 = 0,0125
0,0025 < 0,0125 < 0,1   (✓)

Условие выполняется — метод Фролова-Родзиллера применим.

2. Коэффициент турбулентной диффузии:

E = (H_ср * V_ср) / 200 = (1,5 * 0,42) / 200 = 0,63 / 200 = 0,00315

3. Коэффициент β, учитывающий гидравлические условия смешения. Для берегового выпуска α = 1:

β = α * φ * E = 1 * 1,8 * 0,00315 = 0,00567

4. Параметр τ:

τ = β * √L = 0,00567 * √500 = 0,00567 * 22,36 ≈ 0,1268

5. Коэффициент смешения γ:

γ = (1 - e-τ) / (1 + (Q / q_св) * e-τ)
e-τ = e-0,1268 ≈ 0,8809
Q / q_св = 0,8 / 0,01 = 80
γ = (1 - 0,8809) / (1 + 80 * 0,8809) = 0,1191 / (1 + 70,47) = 0,1191 / 71,47 ≈ 0,00167

6. Кратность основного разбавления:

n_ор = (q_св + γ * Q) / q_св = (0,01 + 0,00167 * 0,8) / 0,01 = (0,01 + 0,00134) / 0,01 = 0,01134 / 0,01 ≈ 1,13

7. Кратность начального разбавления:

Выпуск безнапорный (скорость истечения не задана), поэтому:

n_нр = 1

8. Общая кратность разбавления:

n = n_нр * n_ор = 1 * 1,13 ≈ 1,13

Ответ:

  • Коэффициент турбулентной диффузии: E = 0,00315
  • Коэффициент β: β = 0,00567
  • Параметр τ: τ ≈ 0,127
  • Коэффициент смешения: γ ≈ 0,00167
  • Кратность основного разбавления: n_ор ≈ 1,13
  • Общая кратность разбавления: n ≈ 1,13
